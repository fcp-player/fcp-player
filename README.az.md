# 🇦🇿 Azərbaycan TV və Radio Player

Azərbaycan televiziya kanallarını izləmək və radio stansiyalarını dinləmək üçün müasir Android tətbiqi.

Sevimli yerli kanallarınızı bir yerdə kəşf edin və rahat, sadə, zövqlü interfeys vasitəsilə televiziya və radio yayımından həzz alın.

## ✨ Xüsusiyyətlər

- 📺 **Canlı TV** — Müxtəlif Azərbaycan televiziya kanallarını izləyin.
- 📻 **Radio yayımı** — Azərbaycan radio stansiyalarını dinləyin.
- 🎨 **Müasir interfeys** — Rahat və istifadəsi asan dizayn.
- 📱 **Android dəstəyi** — Android cihazları üçün hazırlanıb.
- ▶️ **Asan idarəetmə** — İstədiyiniz kanal və ya stansiyanı seçərək yayıma başlayın.
- 🇦🇿 **Azərbaycan məzmunu** — Sevimli yerli TV və radio kanallarınız bir tətbiqdə.

## 📲 Quraşdırılma

1. Ən son APK faylını [Releases](../../releases) bölməsindən yükləyin.
2. Yüklənmiş APK faylını Android cihazınızda açın.
3. Tələb olunarsa, həmin mənbədən tətbiq quraşdırılmasına icazə verin.
4. Quraşdırmanı tamamlayın və tətbiqi başladın.
5. İstədiyiniz TV kanalını və ya radio stansiyasını seçərək yayımdan həzz alın!

## 📡 Tələblər

- Android əməliyyat sistemli cihaz.
- Aktiv internet bağlantısı.
- Seçilmiş kanal və ya stansiya üçün işlək və əlçatan yayım mənbələri.

## ⚠️ Məsuliyyətdən imtina

Bu tətbiq televiziya və radio məzmununu yayımlamaq üçün nəzərdə tutulmuş media pleyeridir. Kanalların əlçatanlığı və yayım keyfiyyəti istifadə olunan yayım mənbələrindən və internet bağlantınızdan asılıdır.

Bütün kanal adları, loqolar, ticarət nişanları və yayımlar müvafiq hüquq sahiblərinə məxsusdur. Tətbiq üçüncü tərəflərə məxsus məzmun üzərində hüquq iddia etmir. Yayım mənbələrindən istifadə edərkən qüvvədə olan qanunvericiliyə və məzmun sahiblərinin hüquqlarına riayət edin.
