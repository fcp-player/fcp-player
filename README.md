# 🇦🇿 Azerbaijan TV & Radio Player

A modern Android player for watching Azerbaijani television channels and listening to Azerbaijani radio stations — all in one place.

Enjoy your favorite local channels with a clean, intuitive interface designed to make watching TV and listening to the radio simple and comfortable.

## ✨ Features

- 📺 **Live TV** — Watch available Azerbaijani television channels.
- 📻 **Radio Streaming** — Listen to Azerbaijani radio stations.
- 🎨 **Modern Interface** — A clean and visually appealing player experience.
- 📱 **Android Support** — Designed for Android devices.
- ▶️ **Easy Playback** — Quickly select a channel or station and start streaming.
- 🇦🇿 **Azerbaijani Content** — Your favorite local TV and radio in one application.

## 📲 Installation

1. Download the latest APK from the [Releases](../../releases) page.
2. Open the downloaded APK file on your Android device.
3. Allow installation from this source if Android asks for permission.
4. Complete the installation and launch the application.
5. Select a TV channel or radio station and enjoy!

## 📡 Requirements

- An Android device.
- An active internet connection.
- Available and accessible streaming sources for the selected channel or station.
