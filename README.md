# 🇦🇿 Azerbaijan TV & Radio Player

🇬🇧 English | [🇦🇿 Azərbaycan dili](README.az.md)

A modern Android player for watching Azerbaijani television channels and listening to Azerbaijani radio stations — all in one place.

## ✨ Features

- 📺 **Live TV** — Watch available Azerbaijani television channels.
- 📻 **Radio Streaming** — Listen to Azerbaijani radio stations.
- 🎨 **Modern Interface** — A clean and visually appealing design.
- 📱 **Android Support** — Designed for Android devices.
- ▶️ **Easy Playback** — Select a channel or station and start streaming.
- 🇦🇿 **Azerbaijani Content** — TV and radio in one application.

## 📲 Installation

1. Download the latest APK from [Releases](../../releases).
2. Open the APK file on your Android device.
3. Allow installation from this source if prompted.
4. Install and launch the application.
5. Choose a TV channel or radio station and enjoy!

## 📡 Requirements

- An Android device.
- An active internet connection.
- Available streaming sources for the selected channel or station.
